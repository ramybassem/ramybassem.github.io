# Ramy Basily: Portfolio

I'm a Data Architect in the airline industry. On my own time, I build products that exist for a reason. This repo is the home for that personal portfolio, published with GitHub Pages.

**Live site:** https://ramybassem.github.io/ramy.github.io/

## Pages

- [Home](https://ramybassem.github.io/ramy.github.io/)
- [About me](https://ramybassem.github.io/ramy.github.io/about/)
- Products
  - [ScrollScripture](https://ramybassem.github.io/ramy.github.io/products/scrollscripture/): daily Scripture and reflections in English, Arabic and French
  - [Wellness Compass](https://ramybassem.github.io/ramy.github.io/products/wellness-compass/): my personal health data hub with MCP tools for AI assistants
  - [TNTCalc](https://ramybassem.github.io/ramy.github.io/products/tntcalc/): a free trampoline & tumbling difficulty calculator, built for my sons and their community
  - [MemSynk](https://ramybassem.github.io/ramy.github.io/products/memsynk/): AI memory you own, shared across your AI tools
  - [Aiglo Services](https://ramybassem.github.io/ramy.github.io/products/aiglo-services/): the bilingual e-commerce site I built for my sister's commercial supply business

## What's in this repo

Only the portfolio layer: Markdown pages and a Jekyll config. Product source code lives in separate private repositories.
